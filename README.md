# KDCCE Group Project — Module 6

Group project repository for the KDCCE platform rebuild.

## Structure

- `frontend/` — React + Vite frontend (to be scaffolded)
- `backend/` — Flask backend (to be scaffolded)
- `.env.example` — copy to `.env` and fill in real values before running either app

## Branches

- `main` — integration branch. Do not push directly; merge in via reviewed branches only.
- `<name>-frontend` / `<name>-backend` — one pair per team member for their own work.

## Getting started

This repository is currently a clean structural scaffold — no application code has been added yet. Each member should work on their own `<name>-frontend` or `<name>-backend` branch.
